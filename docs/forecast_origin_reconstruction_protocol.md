# One-origin information reconstruction

Recorded 2026-11-07 as an additive investigation, before inspecting the new archived-event contrasts. This is not preregistration of the completed pilot.

## Fixed target and scope

The origin is **2023-10-01 at 00:00 UTC**, forecasting 2023 Q4, the last origin in the existing rolling evaluation. The immediate event-history and deployment-strength window is July–September 2023; the second deployment lag is April–June 2023. This date was chosen for a bounded end-of-pilot reconstruction, not for favorable count agreement or model performance. No target-quarter outcomes will be used to choose sources or inclusion rules, and no new model will be fitted.

Reconstruct the most recent inputs for which archived evidence can be obtained. Do not claim to have rebuilt all training observations, locality effects, violent-spell histories or historical centering means merely because recent inputs are available. Inventory these remaining requirements explicitly.

## Evidence rules

Distinguish a historical version's documented existence before the cutoff from proof that today's downloadable bytes are identical to that version. A current archive URL, file name, HTTP metadata or present-day release policy alone is not a verified historical publication timestamp. Record provider evidence, dated downstream acquisition evidence and policy-based assumptions separately. A source dated on the cutoff day needs within-day availability evidence; otherwise do not presume it was available at midnight.

Obtain UCDP Candidate July, August and September 2023 releases and preserve URLs, retrieval metadata and hashes. Keep raw and event-level files ignored. Apply the same violence, precision and fixed-geography rules to each vintage's own fields. Audit repeated event identifiers and cross-month records; do not select historical records through membership in the latest GED. Compare identical occurrence-month windows with GED 26.1. A July–August count is a two-month partial observation, never a complete Q3 count. Any full-Q3 Candidate comparison requiring unverified September availability is explicitly conditional and not the certified information set.

Inspect source maps underlying the current Q3 and Q2 strength fields. Seek dated UN publications before the origin; map reference month, report publication and Geo-PKO coding/revision availability are distinct. Do not turn map omission into zero or assert exact personnel counts from narrative presence alone. Retain current strengths only as retrospective comparators unless the historical evidence supports reconstruction.

Use the same 19 fixed analytical localities to make revisions comparable, while acknowledging that the adopted boundary artifact's historical availability is unverified. Mark the existing nine-locality sample only as a comparator, not as an independently established operational population.

## Deliverables and acceptance

Produce source-evidence ledgers, reproducible R comparisons, an explicit missing-information inventory and a short synthesis. Verify source hashes, unique comparison keys, exclusion accounting, same-window counts and preservation of the existing 18-file analysis snapshot. Keep uncertainty distinct from absence; do not fill unknown months with zeros. If complete as-of reconstruction is not supported, report the partial reconstruction and the exact evidence still required. Current empirical estimates, forecasting claims and user-skipped human-review status remain unchanged.
