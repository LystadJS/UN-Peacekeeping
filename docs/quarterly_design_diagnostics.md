# Quarterly predictor design diagnostics

Generated by `scripts/audit_quarterly_design.R` on the nine-locality, 288-quarter panel. No outcome model was fitted. Strength is measured per 1,000 listed military personnel.

The within-locality centered first and second deployment lags have correlation **0.953657**. Including both therefore asks the model to separate highly similar exposure histories; this can inflate uncertainty for the current lag's coefficient. These diagnostics do not establish the cause of any particular simulated fit failure.

Transitions count adjacent changes across the 32 outcome quarters; distinct levels use ten-decimal rounding. Shabunda contributes **no within-locality deployment-strength variation**, although it remains in the exposure-complete sample and may inform other model components.

The ordinary-history fixed-effect design has 12 columns and rank 12, with singular-value condition number **11.02117**. Adding log initial event count and initial violent-spell length produces 14 columns but rank **13**, hence an infinite full-column condition number. This initial-adjusted specification cannot be carried unchanged into the empirical model without addressing its redundant columns. No automatic dropping or model fitting was performed.

All nonconstant numeric predictors are standardized to sample mean zero and sample SD one before matrix construction. Quarter is a four-level factor; province uses treatment contrasts. The condition numbers depend on this coding and describe fixed-effect predictor geometry, not the fitted likelihood or random-effect identification. Aggregate CSV outputs include both lag distributions and matrix diagnostics under `outputs/quarterly_pilot/design/`.
