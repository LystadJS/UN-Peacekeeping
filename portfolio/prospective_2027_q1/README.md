# Frozen research forecasts: 2027 Q1

Experimental forecasts, issued 16 November 2026 for January-March 2027.
The NB2 model's historical predictive advantage is inconsistent. These files
are for a prospective research comparison, not operational protection decisions.

Read SPECIFICATION.md before interpreting frozen_forecasts.csv. The relative
surge threshold uses the latest complete observed year (2025 Q4-2026 Q3).
2026 Q4 remains unknown. The ten-pseudo-observation benchmark is preserved
as a full discrete distribution for independent later scoring.

This archive freezes predictions, not evidence of accuracy. No 2027 outcome
has been scored. Fit success does not establish reliability or causal effects.
The user selected a sharp relative increase; the numerical twice-average/+2
rule is an existing analyst operationalization, not a cutoff selected here.

The source-date audit compares admitted event source dates with the information
freeze date, 16 November 2026. Its inherited column name any_post_origin refers
to that freeze, NOT January 2027. All admitted tokens parse and none fall on or
after the freeze date. This is not proof of complete reporting.

Reproduction scripts require the hashed project data, existing R packages,
SALB2018 geography and the city crosswalk. Raw event files are not redistributed
in this packet. The saved model object remains in outputs/prospective_2027_q1.
The freeze script refuses to overwrite an existing forecast table.

archive_status.csv records the local preparation status; publication is
established by the remote Git commit containing this packet, not local timestamps.
Future corrections must be separate dated files/commits preserving this version.
